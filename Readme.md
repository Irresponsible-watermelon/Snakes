<h1>Snakes</h1>
The purpose of this project is to get a handle of various different methods for making basic, 2D games, by trying to make the classic 'snake game' with each. My ultimate goal from this project is to try out a variety of different ways to make a game, and then use that knowledge to decide how I make my next project, which will be a larger 2D railfreight yard management game. <br><br>
I will also be building a launcher through which the games can be accessed, and the ultimate aim of this project is to determine which engines/gamemaking tools I will using in future ones. I've just finished my PyGame version, and am currently looking at Godot. See the release builds for how to run the game, as some of the details differ slightly across releases. <br><br>
To give the project a spin, download and extract the .Zip file from the latest release and run 'Snake_Launcher.exe', which will allow you to select between diferent versions of the game to try. For the Pygame version, you can also upload your own sprites, with instructions on how to do so contained in "Snake_Launcher/Snake_Game(Pygame)/Assets/asset instructions.txt"

<h2>Snakes - PyGame Edition</h2>
For my first rendition, I made Snake in python using PyGame. I've learn the basics of python and pygame, implemented various modules and explored different ways of achieving the same goal in python. I've created some custom art to go with the game and an interactive UI that allows the users to customise the look and pace of the game.

<h2>Snakes - Godot Edition</h2>
I have now started on making snake in Godot. I've managed to put together a more polished version of the game, and I'm quite happy with the end result, however it definitely took more work than PyGame, but also allows for more complexity. I do like the fact that for most things, there is a set method and process of doing them, where in PyGame you could approach achieving something in alot more ways, which makes it easier to figure out how to get things to work. The Godot dictionary is also super useful, its greata having the tooltips and everything explained.

<h2>Snakes - Unity Edition</h2>
I started the Unity version of the game and so far I despise it. I do like Unity's UI builder, but I don't like C# especially when compared to GodotScript, and I miss how Godot actually tried to work rather than just crashing with no explaination whenever something went wrong. The unity engine also feels quit heavy and seems to be introducing unneccessary complexity which appears to be causing lag for what is a very lightweight and simple game.
