<h1>Snakes</h1>
The purpose of this project is to get a handle of various different methods for making basic, 2D games, by trying to make the classic 'snake game' with each. I will also be building a launcher through which the games can be accessed, and the ultimate aim of this project is to determine which engines/gamemaking tools I will using in future ones.

<h2>Snakes - PyGame Edition</h2>
For my first rendition, I have started by making Snake in python with the help of PyGame. I've figured out many of the basics of both python and pygame, such as syntax, different kinds of variables, loops and more. I've already set up the framework for my game, and now I am hoping to add ways for the user to change some variables to alter their gameplay, and add some artwork to make it pop.
